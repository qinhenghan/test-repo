# 首个爬虫作品 · 中国银行外汇牌价采集

> 这是一个**真实可跑、可直接当接单敲门砖**的爬虫小项目。
> 采集**中国银行官网的实时外汇牌价**（公开数据，无需登录），清洗后输出带样式的 Excel。

## 一、项目文件

```
首个爬虫作品_外汇牌价/
├── boc_fx_crawler.py        # 主脚本（抓取 + 解析 + 清洗 + 导出）
├── README.md                # 本说明
└── output/
    └── 中国银行外汇牌价_20261120.xlsx   # 运行后生成的成品（45 种货币）
```

## 二、怎么运行

```bash
pip install requests beautifulsoup4 openpyxl
py boc_fx_crawler.py
```

- 依赖：`requests`、`beautifulsoup4`、`openpyxl`
- 每次运行会重新抓取最新牌价，生成当天日期的 Excel（`output/中国银行外汇牌价_日期.xlsx`）
- 终端会打印摘要（前 5 条 + 总数 + 发布时间）

## 三、数据源 & 合规

- **数据源**：`https://www.boc.cn/sourcedb/whpj/`（中国银行官网 · 金融市场 · 外汇牌价）
- **类型**：公开金融数据，页面展示用，无需登录、无需接口授权
- **合规**：只抓取公开展示数据、低频单次请求、不采集用户隐私信息；采集结果仅用于学习/展示，不转售、不滥用
- **频率**：脚本默认单次抓取，未做高频轮询，礼貌访问

## 五、清洗逻辑（这是本作品的技术亮点）

脚本在 `parse_page()` 里做了 5 步清洗：

1. **字段提取**：按页面表格列顺序取 9 列，映射到 7 个业务字段
2. **空值处理**：`clean_price()` 去空白、去千分位逗号，空串返回 `None`（如部分币种只公布中行折算价，现汇/现钞买卖为空 → 记为 None，不报错、不填垃圾值）
3. **类型转换**：价格统一转 `float` 并保留 2 位小数
4. **去重**：按`货币名称`去重，保留第一条（页面偶有重复行）
5. **排序 + 时间拆分**：按货币名称排序；把 `发布时间`拆成`发布日期`+`更新时间`两列，便于后续按日期筛选分析
